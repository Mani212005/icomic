# Known Issues in Backend and AI Service

This document records defects identified during end-to-end integration testing (`tests/e2e/`).
Per the task instructions, defects in existing backend or AI code are documented here with exact reproductions rather than modified in this work package, enabling the orchestrator to dispatch targeted fixes.

---

### Issue 1: `FakeStorageAdapter` Hardcodes Port 8000 & `DownloadExport` Fallback Proxy Fails on Ephemeral Ports

- **Component**: `ai/app/adapters/storage/fake.py`, `ai/app/adapters/factory.py`, and `backend/internal/api/handlers.go`
- **Severity**: Medium (Impacts standalone test setups on ephemeral ports when port 8000 is occupied)
- **Status**: Mitigated in test suite via transparent port 8000 forwarder when port 8000 is available; requires upstream fix for fully port-agnostic operation.

#### Description & Root Cause

1. **AI Service Side (`ai/app/adapters/storage/fake.py:11` & `ai/app/adapters/factory.py:68`)**:
   `FakeStorageAdapter` initializes with a hardcoded `base_url`:
   ```python
   def __init__(self, base_url: str = "http://localhost:8000/storage/fake"):
       self.base_url = base_url.rstrip("/")
   ```
   In `ai/app/adapters/factory.py`, `get_storage_adapter()` instantiates `FakeStorageAdapter()` with zero arguments and does not read any configuration or environment variable (e.g. `STORAGE_BASE_URL`).
   When `assemble_pdf` stores the compiled comic PDF, it generates an absolute download URL using this default:
   `http://localhost:8000/storage/fake/exports/<project_id>/comic.pdf`.

2. **Go Backend Side (`backend/internal/api/handlers.go:1996-2012`)**:
   In `DownloadExport`, the Go handler attempts to retrieve the PDF:
   ```go
   // Proxy to Python fake storage if AIClient has BaseURL
   if s.AIClient != nil {
       if client, ok := s.AIClient.(*gen.AIServiceClient); ok && client.BaseURL != "" {
           cleanKey := strings.TrimPrefix(fileURL, "/")
           targetURL := strings.TrimRight(client.BaseURL, "/") + "/storage/fake/" + cleanKey
           req, err := http.NewRequestWithContext(r.Context(), http.MethodGet, targetURL, nil)
           if err == nil {
               resp, err := http.DefaultClient.Do(req)
               if err == nil && resp.StatusCode == http.StatusOK {
                   defer resp.Body.Close()
                   w.WriteHeader(http.StatusOK)
                   _, _ = io.Copy(w, resp.Body)
                   return
               }
           }
       }
   }
   ```
   If the Python AI service is listening on an ephemeral port (e.g. `45678`), the direct request to `http://localhost:8000` fails with a connection error.
   The fallback proxy logic then attempts to construct `targetURL`. However, because `fileURL` is absolute (`"http://localhost:8000/storage/fake/exports/..."`), `strings.TrimPrefix(fileURL, "/")` does not remove the scheme or host.
   The resulting `targetURL` is:
   `http://127.0.0.1:45678/storage/fake/http://localhost:8000/storage/fake/exports/...`

3. **FastAPI Route Side (`ai/app/main.py:301-316`)**:
   FastAPI receives the path parameter `key:path` and runs:
   ```python
   clean = key.lstrip("/")
   norm = posixpath.normpath(clean)
   ```
   `posixpath.normpath` collapses `//` into a single `/`, converting `http://localhost:8000/...` into `http:/localhost:8000/...`.
   `FakeStorageAdapter.get()` attempts to look up `http:/localhost:8000/...` in `self._blobs`, which fails, raising `KeyError` and returning HTTP 404:
   `{"code":"NOT_FOUND","message":"Storage object 'http://localhost:8000/storage/fake/exports/...' not found."}`

4. **Fallback to Stub**:
   Because the proxy returns 404, Go falls back to writing the 3-line stub PDF:
   ```go
   w.WriteHeader(http.StatusOK)
   _, _ = w.Write([]byte("%PDF-1.4\n% Assembled comic export\n%%EOF\n"))
   ```
   This stub PDF does not contain the multi-page layout, mandatory AI disclosure statements, or C2PA provenance metadata generated by the AI service.

#### Exact Reproduction

```bash
# 1. Start Python AI service on ephemeral port (e.g. 45678)
cd ai && uv run uvicorn app.main:app --port 45678

# 2. Start Go API server on ephemeral port (e.g. 45679) pointing to Python AI
cd backend && PORT=45679 PYTHON_AI_URL=http://127.0.0.1:45678 DEV_AUTH_ENABLED=true go run cmd/server/main.go

# 3. Create project, approve stages, export, and download PDF
# (Port 8000 must NOT be running)
curl -H "X-User-ID: 00000000-0000-0000-0000-000000000001" http://127.0.0.1:45679/api/v1/exports/<export_id>/download
# -> Returns the 3-line fallback stub PDF instead of the assembled PDF.
```

#### Recommended Fix for Follow-Up Package

1. **In `ai/app/adapters/storage/fake.py` & `ai/app/adapters/factory.py`**:
   Read `STORAGE_BASE_URL` from the environment if present:
   ```python
   base_url = os.getenv("STORAGE_BASE_URL", "http://localhost:8000/storage/fake")
   return FakeStorageAdapter(base_url=base_url)
   ```
2. **In `backend/internal/api/handlers.go` (`DownloadExport`)**:
   Sanitize `cleanKey` by stripping any URL prefix up to `/storage/fake/`:
   ```go
   cleanKey := fileURL
   if idx := strings.Index(cleanKey, "/storage/fake/"); idx != -1 {
       cleanKey = cleanKey[idx+len("/storage/fake/"):]
   } else {
       cleanKey = strings.TrimPrefix(cleanKey, "/")
   }
   targetURL := strings.TrimRight(client.BaseURL, "/") + "/storage/fake/" + cleanKey
   ```

#### Test Suite Mitigation

In `tests/e2e/conftest.py`, the test suite automatically binds a local TCP forwarder on port 8000 (when port 8000 is available) to route port 8000 traffic directly to the ephemeral Python AI port. This allows the full end-to-end happy path and PDF verification to pass cleanly on standard test runners and in CI.
